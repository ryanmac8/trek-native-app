# Features

What's actually implemented, not what's planned — see [ROADMAP.md](ROADMAP.md) for the feature plan and tracking issues. Update this file whenever a feature is added or its status changes.

| Feature | Status | Details |
| --- | --- | --- |
| Self-hosted server configuration | Has UI | A public server URL and an optional private (LAN) URL, with automatic switching to the private one on trusted Wi-Fi networks. Entered via `ServerSetupScreen`. See [networking-auth.md](networking-auth.md) and [app-shell.md](app-shell.md). |
| Account authentication | Has UI | Login, TOTP MFA, logout, and expiry-aware session persistence, against Trek's single-JWT session model. `LoginScreen`/`MfaScreen` wire this into the app shell; the router redirects between server setup, login, and the trip list automatically as auth state changes. See [networking-auth.md](networking-auth.md) and [app-shell.md](app-shell.md). |
| App shell (navigation, state management, design system) | Foundational, one feature screen | Riverpod + go_router + a Material 3 design system (including Trek's place category colors), a global snackbar messenger, and a reusable UI kit (empty/loading/skeleton states, cards, list rows). Trip list and trip dashboard (with Days/Places/Budget/Packing/Todos tabs) exist as placeholders — no trip data model yet; weather is the first real feature screen. See [app-shell.md](app-shell.md). |
| Weather | Has UI | The `/weather` screen (reached from the trip list's app-bar weather icon) shows current conditions and a seven-day forecast for a picked destination, against `GET /api/weather`. Reads go through `WeatherRepository`: a still-fresh answer paints from a local `shared_preferences` cache with no request, and a failed refresh falls back to the last cached answer (per day) behind an offline notice instead of blanking or throwing. Also adds the app's first authenticated (bearer-token) `ApiClient`. Destinations come from a small bundled list (no trips, places, or geocoding yet); no inline itinerary weather, no hourly breakdown, no Fahrenheit. See [weather.md](weather.md). |
| App icon, splash screen & startup animation | Done | The real Trek T-mark (from the web client's source SVG) as the app icon and native launch image, plus an animated in-app splash screen styled after Trek's web login screen. See [app-shell.md](app-shell.md#app-icon-splash-image-and-startup-animation). |
