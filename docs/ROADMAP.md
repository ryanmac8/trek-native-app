# Roadmap

Trek native is being built against Trek's existing feature set (trips, itineraries, budgeting, packing, collaboration, Atlas, Vacay, Journey, etc.) plus native-platform capabilities the PWA can't offer. The full breakdown lives as GitHub issues on the [Trek MVP project board](https://github.com/users/ryanmac8/projects/1); this doc mirrors it for quick in-repo reference.

Each issue below is an epic with its own checklist of concrete sub-features — open the issue for details.

Core trip planning parity, plus the networking/auth/architecture foundation everything else builds on.
